# Race forms — Dragon Legend

Maximum level: **2,000**. Saiyan and Half-Saiyan have the same 21 form options. Levels are entry requirements; mastery stages and story quests impose additional requirements.

## Shared Saiyan and Half-Saiyan progression

- **Primal mastery:** Oozaru (Lv. 100) → Golden Oozaru (1,000 Oozaru mastery points) → Super Saiyan 4 (2,000 Golden Oozaru mastery points).
- **Super Saiyan mastery:** Super Saiyan (Lv. 250) → Grade 2 / Super Vegeta (250 mastery) → Grade 3 / Super Trunks (500 mastery) → Full Power Super Saiyan (1,000 mastery). These grades share the SSJ mastery counter.
- **Higher stages:** Super Saiyan 2 (Lv. 500, requires Full Power) → Super Saiyan 3 (750) → Super Saiyan God (1,000) → Super Saiyan Blue (1,250).
- **Rage:** 1,200 Super Saiyan 2 mastery points plus the Goku Black/Zamasu story milestone.
- **Other unlocks:** False Super Saiyan (150), Kaioken (250), Kaioken ×10 (500), Legendary Super Saiyan / Broly (1,400).
- **At level 2,000:** choose one persistent path: Beast, Ultra Instinct, or Ultra Ego. Each still requires its unlock quests.

## Endgame paths

| Path | Progression |
|---|---|
| Beast | Gohan training → Beast |
| Ultra Instinct | Tournament of Power Sign/Omen → Perfected UI → Moro-era mastery under Merus → True UI through the Granolah/Gas storyline |
| Ultra Ego | Beerus’s Destruction training and the Granolah story → Ultra Ego |

“Perfected” and “Mastered” describe the same silver-haired transformation here. Moro training improves its control rather than inventing another hair-color form. The black-haired True UI variant is a later branch stage. The giant energy avatar is not treated as a separate transformation.

The separately learned **Ultra Instinct -Sign- technique** remains available: 10% temporary dodge chance, no transformation stat multiplier, slower dodge recovery. Full UI forms have 35–60% dodge chance and 5–6.2× stat multipliers. Neither grants unconditional invulnerability.

## Mastery, controls and saves

Active movement/ki training earns 2 mastery points per second; landed hits add 3 and defeated enemies add 25. Idle standing, menus and death do not earn mastery. The menu displays mastery levels at 10 points per mastery level. Evolution retains earlier unlocks, allows direct selection, and preserves shared SSJ mastery when changing grades.

Use the **Forms** menu to select an unlocked form or return to Base; **T** still cycles forms. Ki costs scale with the level’s baseline pool; Ki stat investment adds endurance without increasing costs. Recovery scales with the actual pool. God Ki reduces transformation drain, and Merus’s mastery quest improves UI drain further.

Save schema v4 retains legacy ids/quest records and maps old Half-Saiyan SSJ unlocks to the shared ids. Old levels scale tenfold once (level 1 stays 1), preserve XP progress, and award stat points for the expanded level interval. Existing unlocks remain saved.
